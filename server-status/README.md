# 服务器状态

在用户询问服务器或 NAS 状态时，Agent 先通过已关联的终端/SSH 环境执行只读查询，再调用 `plugin_server_status_show_status`，把本轮结果显示为对话卡片。插件本身不连接服务器、不保存 SSH 凭据，也不自动刷新。每次提问都会生成一张新的快照卡片。

卡片包含服务器名称、在线状态，以及实际采集到的运行时长、核心数、内存总量、温度、CPU/内存使用率、网络速率、磁盘使用率。未采集到的指标会省略；查询失败时可只传 `name` 和 `online:false` 展示离线状态。温度需要服务器提供传感器数据。

## 安装与使用

1. 在 App 的「能力管理 → 插件库」安装「服务器状态」，并把它添加到需要监控服务器的 Agent。
2. 给该 Agent 关联 SSH 环境并启用终端能力。
3. 在对话中询问“看看 NAS 状态”。Agent 查询后调用 `show_status`；卡片里的数值应来自刚完成的查询。

插件使用 `cuebo-v1` 原生卡片协议。它只负责显示，不能直接读取 SSH 环境。CPU 使用率和网络速率需要两次采样计算，不能用系统负载或累计网络字节数代替。
