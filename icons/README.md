# 插件图标来源

- `basic-cards.png`、`server-status.png`：cuebo 为插件目录绘制的图标。
- `cloudflare.png`：cuebo 为 Cloudflare 集成绘制的通用云图标，不使用 Cloudflare 官方商标图形。
- `github.png`：GitHub 品牌资源包中的 `GitHub_Invertocat_Black_Clearspace.png`，用于标识 GitHub 集成；[官方品牌页](https://brand.github.com/foundations/logo)。
- `telegram-groups.png`：Telegram 官网资源包中的 `Logo.png`，等比例缩小为 256×256；[官方媒体页](https://telegram.org/press)。

GitHub 与 Telegram 插件由 cuebo 提供，并非两家公司的官方应用。
