# 基础卡片

1.4.0 将旧的链接列表、指标格、通用页面和独立图表工具合并为 `show_cards`。Agent 一次提供 1 至 6 张卡片，只填有真实依据的字段；模型不生成 UI 节点。

一张卡片可以包含：抬头与图标、主要信息、事实行、资源、趋势数据、步骤进度、底部信息和最多两个真实网页操作。这些部分自由组合，因此日程、文件、经营数据、物流、天气、设备状态等场景共用一种视觉样式。没有数据的部分省略，不补造内容。

```json
{
  "cards": [
    {
      "title": "订单进度",
      "subtitle": "订单号 DP784392",
      "icon": "shippingbox",
      "accent": "orange",
      "headline": "运输中",
      "detail": "预计周五送达",
      "steps": [{"title":"已发货"},{"title":"运输中"},{"title":"派送中"}],
      "current_step": 1
    }
  ]
}
```

插件首页展示六张标有演示用途的预览卡片，旧组件目录保留在二级页。`show_cards` 的网页链接仅接受 HTTP(S)。新卡片使用 `cuebo-v1` 的 `showcaseCard` 组件，运行它需要包含该渲染器的 App 版本；App 内置的 1.4.0 与此目录保持一致。
