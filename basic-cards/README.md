# 基础卡片

1.6.0 用左右两列展示多张紧凑卡片；只展示一张时保持单列。Agent 一次提供 1 至 6 张卡片，只填有真实依据的字段；模型不生成 UI 节点。

一张卡片可以包含：抬头与图标、主要信息、事实行、资源、趋势数据、步骤进度、底部信息和最多两个真实网页操作。这些部分自由组合，因此日程、文件、经营数据、物流、天气、设备状态等场景共用一种视觉样式。没有数据的部分省略，不补造内容。

```json
{
  "cards": [
    {
      "title": "订单进度",
      "subtitle": "订单号 DP784392",
      "icon": "shippingbox",
      "accent": "orange",
      "headline": "运输中",
      "detail": "预计周五送达",
      "steps": [{"title":"已发货"},{"title":"运输中"},{"title":"派送中"}],
      "current_step": 1
    }
  ]
}
```

插件首页展示六张标有演示用途的预览卡片，旧组件目录保留在二级页。`show_cards` 的网页链接仅接受 HTTP(S)。两列布局、18 点主标题字号与内容组合由 `main.js` 定义，输出通用的 `cuebo-v1` 节点。长底部信息自动改为竖排，避免窄屏截断。App 只需支持通用组件的紧凑图标、按钮和进度样式。App 内置的 1.6.0 与此目录保持一致。
